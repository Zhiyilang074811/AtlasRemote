# Redmi Note 13 5G 连接指南

## 开启开发者模式

1. 打开 **设置**
2. 点击 **我的设备**
3. 点击 **全部参数**
4. 连续点击 **MIUI 版本** 或 **HyperOS 版本** 7 次
5. 提示 "您已处于开发者模式"

## 开启 USB 调试

1. 返回设置主页
2. 点击 **更多设置**
3. 点击 **开发者选项**
4. 开启 **USB 调试**
5. 开启 **USB 安装**（可选）

## 连接电脑

1. 使用 USB 数据线连接手机和电脑
2. 手机上弹出对话框，勾选 **始终允许**
3. 点击 **允许**

## 验证连接

```powershell
adb devices
```

应该看到：

```
xxxxxxxxxxxxxx    device
```

## 常见问题

### 找不到设备
- 确保 USB 调试已开启
- 尝试更换 USB 线（使用原装线）
- 尝试不同的 USB 端口
- 在手机上重新点击 **允许**

### 权限被拒绝
- 在手机上重新授权
- 取消勾选 **USB 调试**，重新开启

### 驱动问题
Redmi Note 13 5G 通常不需要额外驱动。
如果无法识别，安装小米 USB 驱动。
